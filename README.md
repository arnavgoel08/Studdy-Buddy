# Study Buddy

A notebook-style study workspace for instant study planning, task tracking, voice task reading, and optional browser-based tutoring.

**Live app:** https://studdy-buddy-student.vercel.app/

This repository contains the static browser edition. The planner runs locally in JavaScript; study plans and progress are stored in the current browser and are not synced across devices. Optional AI tutoring is experimental and requires compatible browser WebGPU support.

See the project documentation for setup, architecture, limitations, testing, privacy, and deployment details.
